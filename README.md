# Woo Checkout Field Manager

A complete WooCommerce checkout field manager to customize, hide, and reorder billing, shipping, and order fields.

## Features

- Enable or disable checkout fields. Disabled fields are completely removed from the frontend and skip validation.
- Change field labels.
- Set custom placeholders.
- Mark fields as required or optional.
- Change the display priority (order) of fields.
- Fully compatible with High-Performance Order Storage (HPOS).
- Native WordPress UI without bloat.

## Installation

1. Download the plugin as a ZIP.
2. Go to **Plugins > Add New** in your WordPress admin dashboard.
3. Upload the ZIP and click **Install Now**.
4. Activate the plugin.

## Usage

1. Go to **WooCommerce > Checkout Fields** in your admin menu.
2. Edit the fields as needed.
3. Click **Save Changes**.
